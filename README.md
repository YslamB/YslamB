## About me

Go is my primary language, and I learn best by building.

My repositories trace a path from focused backend experiments, such as database
helpers, logging, rate limiting, and recommendation logic, toward larger
questions: how to structure services, manage secrets, process work concurrently,
and keep systems understandable as they grow.

These days I am focused on:

- Designing maintainable Go services with DDD and clean architecture
- Building REST and gRPC APIs backed by PostgreSQL, Redis, and ClickHouse
- Working with queues, worker pools, Kafka, and concurrent processing
- Packaging and operating services with Docker and Linux
- Exploring Rust when I want to think closer to the system

environments, and code whose structure explains the system. I am especially
drawn to problems where application design meets real operational constraints.
